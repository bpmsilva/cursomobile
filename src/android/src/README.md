# Projetos Android

## Informações Gerais

Aqui estão contidos os projetos desenvolvidos durante o semestre de 2026.2, com foco no desenvolvimento de aplicativos Android utilizando Java e Kotlin.

## Projetos

- 01) Olá, Mundo!: Simples aplicativo apenas utilizado para verificar o funcionamento do Android Studio e do emulador ou dispositivo físico.
- 02) ConstraintLayout: Demonstra uso do ConstraintLayout para organizar os elementos da interface.
- 03) Eventos de Clique (Java): Demonstra a captura de eventos de clique em um botão.
- 04) Contador de Cliques (Java): Aplicativo que incrementa um contador a cada clique em um botão.
- 05) Android XML: Construção de layouts utilizando XML.
- 06) Linear e Constraint Layouts: Comparação e combinação de LinearLayout e ConstraintLayout.
- 07) Click type: Demonstra diferentes tipos de eventos de clique e suas implementações. `TODO: finalizar o aplicativo colocando todos os tipos de tratamento de cliques.`
- 08) Boas práticas: extração de cores, strings, uso de estilos e temas para melhor organização do projeto.
- 09) Exemplo de ListView: Demonstra o uso do componente ListView para exibir listas de itens.
- 10) Exemplificação de SharedPreferences: exibe quantas vezes o aplicativo foi fechado e reaberto, utilizando SharedPreferences para armazenar o contador.
- 11) Contador de Cliques (Kotlin): Reimplementação do aplicativo de contador de cliques utilizando Kotlin.
- 12) Exemplo completo de ListView que permite adicionar elementos à lista.
- 13) Exemplo do uso de RecyclerView utilizando Kotlin.
- 14) Exemplo do uso de RecyclerView utilizando Java para comparar com a implementação em Kotlin.
