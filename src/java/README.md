# Linguagem de Programação Java

## Introdução

Java é uma linguagem de programação orientada a objetos e é suportada no desenvolvimento de aplicativos Android. Os trechos de código desta pasta introduzem os principais conceitos e fundamentos da linguagem Java, fornecendo uma base sólida para o desenvolvimento de aplicativos Android.

Os tópicos abordados incluem:

- **Sintaxe Básica**;
- **Leitura de Dados**;
- **Variáveis e Constantes**;
- **Tipos de Dados**;
- **Operadores**;
- **Estruturas de Controle**;
- **Métodos**;
- **Programação Orientada a Objetos**:
    - **Sintaxe Básica**;
    - **Classes e Objetos**;
    - **Atributos**;
    - **Encapsulamento**;
    - **Herança**;
    - **Polimorfismo**;
    - **Interfaces**;
- **Tratamento de Exceções**;

## Ambiente de Desenvolvimento

Para executar os exemplos de código Java no laboratório podemos utilizar, por exemplo, o Eclipse ou o próprio Android Studio. Ambos os ambientes oferecem suporte completo para desenvolvimento em Java e já estão instalados no laboratório. Iremos utilizar os dois ambientes de desenvolvimento para consolidar os conceitos de Java. Inicialmente, iremos utilizar o Eclipse, e posteriormente, utilizaremos o Android Studio.

No caso do Android Studio, é necessário criar um projeto Android para executar os exemplos de código Java. Você deve criar uma classe Java dentro do projeto e, em seguida, executar o código com comando Run 'NomeDaClasse'. Isso pode ser feito através do botão direito do mouse na classe e selecione Run 'NomeDaClasse', cujo atalho é `Ctrl + Shift + F10`.
