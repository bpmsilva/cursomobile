# Linguagem de Programação Java

Java é uma linguagem de programação orientada a objetos e é suportada no desenvolvimento de aplicativos Android. Os trechos de código desta pasta introduzem os principais conceitos e fundamentos da linguagem Java, fornecendo uma base sólida para o desenvolvimento de aplicativos Android.

Os tópicos abordados incluem:

- **Sintaxe Básica**;
- **Leitura de Dados**;
- **Variáveis e Constantes**;
- **Tipos de Dados**;
- **Operadores**;
- **Estruturas de Controle**;
- **Métodos**;
- **Programação Orientada a Objetos**:
    - **Sintaxe Básica**;
    - **Classes e Objetos**;
    - **Atributos**;
    - **Encapsulamento**;
    - **Herança**;
    - **Polimorfismo**;
    - **Interfaces**;
- **Tratamento de Exceções**;
